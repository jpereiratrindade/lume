# Premissas compartilhadas

**Simples, leve. Sempre pronto. Sempre incompleto!**

| Símbolo | Premissa | Compromisso |
| --- | --- | --- |
| ![Pena](simple-light.svg) | Simples, leve. | Poucos elementos e recursos proporcionais ao propósito. |
| ![Círculo com confirmação](always-ready.svg) | Sempre pronto. | Uma realização utilizável dentro do escopo atual, com limites explícitos. |
| ![Ciclo aberto](always-incomplete.svg) | Sempre incompleto! | Evolução contínua, com espaço para revisão e aprendizagem. |

Os símbolos representam princípios de desenvolvimento. Não são indicadores de
conexão, disponibilidade, identidade verificada ou validação científica.

SVGs locais, sem fontes, scripts, animações ou dependências externas. O texto
acompanha os símbolos nas interfaces; ícones decorativos usam `aria-hidden`.
As cores acompanham a identidade de cada projeto.
